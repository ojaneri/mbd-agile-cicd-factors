# E3 — Standards evidence produced by the pipeline (RQ3)

Status: **planned, not run.** Supports [[claims/c2-standards-traceability]].

## Setup
- For each release produced in E2, list the verification and configuration work products the
  pipeline emits automatically: requirement-to-test links, test reports per stage, coverage, model
  and code versions, build provenance, signed package hash, change log.
- Map each work product to the ISO 26262 (Parts 6 and 8) and ISO 21434 clauses that require it,
  **cited against the official text** (R10). Entries not checked against the text stay marked
  unverified and do not enter the paper.

## Metrics
- Share of mapped work products generated without a manual step.
- Manual steps per release, and the time they take (estimated, labelled as estimate).
- Requirement-to-test trace coverage per release.
