# Claim C1: Integrating MBD, Agile and CI/CD shortens the release cycle

statement: A combined process (MBD for models and SIL/MIL/HIL validation, Agile for backlog and sprints, CI/CD for build, test and OTA release) reduces lead time from feature to validated release compared with each method applied alone.

current evidence: none yet. Infographics and literature are qualitative.

what would falsify it: equal or longer lead time in the integrated case when measured on the same feature set and team, or no reduction in defects escaping to HIL.

planned measurement: lead time per increment, number of pipeline stages run per commit, defects found per stage. Needs a real or reproducible case (candidate: ECU/ADAS model with a Simulink-to-code pipeline).
